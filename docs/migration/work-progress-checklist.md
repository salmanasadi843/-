## کارهای باقی‌مانده (به ترتیب اولویت)
- [ ] **P0 — بازبینی سلسله‌مراتب UI:** نمایش و پیمایش دقیق «استاد ← کلاس ← جلسه» در Android و وب؛ پوشه/دوره صرفاً دسته‌بندی اختیاری، نه جایگزین استاد یا کلاس. مورد گزارش‌شده قبلی: صفحه مدیریت فقط کلاس نشان می‌داد و استاد/کلاس درس درست دیده نمی‌شد.
- [ ] **P0 — مدیریت مدیر اصلی:** آزمون end-to-end که مدیر بتواند کلاس/جلسه همه استادان را ببیند، ویرایش/حذف/بازیابی کند؛ استاد دیگر فقط‌خواندنی و بدون امکان تغییر/پنهان‌سازی محتوای دیگران باشد.
- [ ] **P0 — امن‌سازی bootstrap مدیر:** تعیین مدیر اصلی فقط از مسیر امن سمت سرور؛ عدم اعطای نقش با ایمیل یا ورودی کلاینت.
- [ ] **P1 — اتصال UI وب به API واقعی:** نمایش استاد/کلاس/جلسه و اعمال مجوز عمومی/خصوصی در جریان واقعی، نه فقط صفحه/endpoint آزمایشی.
- [ ] **P1 — اتصال Android adapter به API:** پس از تثبیت قرارداد و تست؛ حفظ Room و Firebase فعلی تا زمان تأیید اتصال، بدون migration مخرب.
- [ ] **P1 — پنل عضویت و تالار/اعلان:** اتصال به صفحه/کلاس و آزمون نقش و مجوز در Backend و UI.
- [ ] **P1 — آزمون دستی روی دستگاه و وب:** ورود، مهمان، کلاس عمومی/خصوصی، عضویت/لغو، استاد دیگر، مدیر، انتقال جلسه بین کلاس‌ها و جابه‌جایی/اولویت.
- [ ] **P2 — موجودی read-only داده قدیمی:** ابزار/مشخصات inventory با داده مصنوعی؛ موارد مالکیت نامعلوم در قرنطینه، بدون انتقال واقعی.
- [ ] **P2 — بررسی کامل Backup/Restore Room و نگاشت UID:** فقط پس از مسیر بازیابی معتبر؛ هیچ تغییر schema با fallback مخرب بدون برنامه امن.
- [ ] **P2 — انتشار:** بازبینی امنیت، سبز بودن همه CIها، رفع موارد باقی‌مانده و تبدیل PRهای Draft به Ready/Merge با تصمیم جداگانه.
